# 文档问答系统使用说明

## 打开与关闭

先按 README 安装环境并运行 `bash scripts/start.sh`；macOS 也可先执行 `zsh scripts/build_app.sh`，再双击“文档问答.app”，等窗口显示“服务已就绪”，浏览器会打开工作台。App 图标采用文档页、检索光束和视觉节点的主题设计，便于在访达或程序坞中识别。没有自动打开时，点击 App 的“打开问答页面”。端口被其他程序占用时会自动选择空闲端口，以 App 打开的地址为准。

结束使用时关闭 **App 窗口**，或点击“退出并关闭服务”。只关闭浏览器标签页不会停止服务。Ollama 是独立应用，项目退出不会强制关闭它。启动失败时可点击“查看启动日志”；不要反复启动多个副本。

## 第一次问答

1. 打开“文档管理”，上传 PDF、Word 或图片，等待解析完成。大文件和扫描页会更慢。相同文件再次上传会复用已有记录。
2. 在侧栏“切换生成模型”选择“Ollama 本地生成”，应用模型，然后检查连接。请先下载并配置 Qwen2.5-VL 7B；检查连接只确认服务及模型存在，实际能力通过提问检验。
3. 打开“文档问答”，选择需要查询的文档范围。多个年份报告包含相似数据时，在问题中写明报告名、年份和统计口径。
4. 提交问题，阅读回答后展开证据，点击“查看原页与高亮”，核对数字、单位、表头和来源页码。
5. 切换资料后建议新建会话，避免先前追问的语境影响新问题。

可用现有公开报告试问：“据《2023年12月全国城市空气质量报告》，当月全国地级及以上城市的平均空气质量优良天数比例是多少？”也可询问文档没有提供的信息，检查系统能否说明证据不足。

## 两种模型如何选择

| 界面选项 | 使用条件 | 适用方式 |
|---|---|---|
| 百炼云端 / Qwen3-VL Plus | 网络及百炼 API Key | 使用账号额度，超额费用以百炼控制台为准 |
| Ollama 本地 / Qwen2.5-VL 7B | 本机 Ollama 运行、模型已下载 | 不消耗百炼额度，占用本机内存与计算资源 |

模型直接在界面切换并应用，不需要修改代码。百炼的模型版本日期保留在实验记录中，界面名称不显示日期。日常练习可使用本地模型；长文本、多张图片的回答可能较慢。用户界面只展示回答、状态和证据定位，不展示 Token、项目调用预算或云端剩余额度；这些信息如需复核只在后台回答记录和实验材料中保留。连接检查不等于答案正确性验收。

没有可用生成模型时，仍可使用“检索分析”查原文。不要将检索片段或错误信息当成模型完成的回答。引用编号有效也不保证结论正确，应核对证据内容。

## 检索与报告数据

“检索分析”用于比较关键词检索、语义检索、融合与重排序。结果包含来源和各检索通道，适合解释系统如何找到证据。

软件界面不展示实验结果和模型对比。需要生成评测数据时，运行 [实验说明](evaluation.md) 中的命令行脚本；实验 JSON、逐题 CSV、模型对照和评分表保存在 `data/`，不会因为隐藏界面而删除。暂停续跑、人工评分和对照核验也属于报告工作流。

实验数据只供报告和复核使用。评分表填写 reviewer（评分人）、answer_accuracy（0、0.5 或 1）、is_refusal（1 是、0 否）、citation_supported（1 支持、0 不支持，未核查留空）及 note；保持问题、回答、实验 ID、题目 ID 和摘要列不变。空白项不会自动记为 0 分，正式盲评继续使用 `export_blind_review.py` 生成的材料。

## 数据与故障处理

- 文档和历史记录保存在项目 `data` 目录；需要备份时先关闭 App，再复制整个 `data` 目录。不要在程序运行时只复制数据库文件。
- `.env` 含私有配置，不要随项目公开提交；实验结果也可能包含上传文档原文，分享前核对内容。
- 本地模型连接失败：先打开 Ollama，确认所选模型已下载，再点连接检查。
- 本地回答很慢：减少同时运行的任务，先问一个明确的问题。默认本地单次请求等待上限为 300 秒；超时记录会保留，不能当成正确拒答。
- 解析失败：在文档管理查看原因并重试；复杂 Word 排版或低清扫描件可先转成清晰 PDF。支持文件扩展名不代表任意版式都经过验收。
